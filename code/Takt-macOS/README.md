Takt для macOS
================

Минималистичное нативное приложение на Swift (AppKit + SwiftUI) без сторонних зависимостей и без выхода в интернет.

Приложение трекает % заряда на устройствах и напоминает, что их пора заряжать. Каждые 3 часа (можно настраивать) напоминает, что пора пить или размяться.

Запуск требует наличие xcode на маке!

Установка за 1 команду (без кавычек и обратных апострофов):

    cd ~/Downloads/Takt-macOS && chmod +x build_app.sh && ./build_app.sh

Скрипт сам соберёт Takt.app с иконкой, скопирует в /Applications и запустит приложение.

Если система попросит инструменты разработчика:

    xcode-select --install
